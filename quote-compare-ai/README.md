# Quote Compare AI

LLM-powered extraction and side-by-side comparison of unstructured insurance
quote PDFs — a minimal proof of concept for the "quote comparison" workflow
common in insurtech products.

Three different (synthetic) carrier quotes go in, each written with its own
layout and terminology. One consistent, comparable table comes out.

## Why this exists

Insurance quotes from different carriers describe the same underlying facts
in inconsistent ways — "Deductible" vs. "Retention" vs. "Per-Occurrence Cap,"
different date formats, exclusions buried in prose. A human has to read each
one carefully to compare them. This project shows the core building block for
automating that: PDF → LLM-normalized JSON → comparison table.

## How it works

```
sample_quotes/*.pdf  --(pdfplumber)-->  raw text
                     --(Claude API)-->  normalized JSON per carrier
                     --(pandas)------>  ranked comparison table (CSV + console)
```

1. **`generate_sample_quotes.py`** — creates 3 synthetic commercial liability
   quote PDFs, each with a deliberately different layout/wording, so the
   extraction step can't just pattern-match one template.
2. **`extract.py`** — reads each PDF's text and asks Claude to return a fixed
   JSON schema (carrier, premium, limits, deductible, exclusions, etc.),
   regardless of how the source document phrased or ordered that info.
3. **`compare.py`** — loads the extracted records and builds a ranked,
   side-by-side comparison table (cheapest premium first), saved as CSV.

## Running it yourself

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY=sk-ant-...

cd src
python generate_sample_quotes.py                 # creates sample_quotes/*.pdf
python extract.py ../sample_quotes ../sample_output/extracted.json
python compare.py ../sample_output/extracted.json ../sample_output/comparison.csv
```

## What I'd extend this into

- Confidence scoring / flagging fields the model couldn't find rather than
  silently returning `null`
- A structured-output mode (JSON schema enforcement) instead of prompt-only
  formatting instructions
- Support for scanned/image-only PDFs via OCR before the text extraction step
- A small Streamlit or React front end for uploading quotes and viewing the
  comparison table interactively
- Batch processing with retries and per-field diffing against a "target"
  policy the buyer specified

## Project structure

```
quote-compare-ai/
├── src/
│   ├── generate_sample_quotes.py   # creates synthetic demo PDFs
│   ├── extract.py                  # PDF -> normalized JSON via Claude
│   └── compare.py                  # JSON records -> ranked comparison table
├── sample_quotes/                  # generated demo PDFs (3 carriers)
├── sample_output/
│   ├── extracted.json              # structured records from extract.py
│   └── comparison.csv              # final comparison table
└── requirements.txt
```

## Note on the sample data

The three sample quotes are entirely synthetic, generated by
`generate_sample_quotes.py` for demo purposes only — no real carrier or
client data is used anywhere in this repo.
